# CET Words 自动更新源
#
# 每行一个 update.json 地址。启动时检查全部来源，优先使用前面的来源；
# 下载失败或校验失败时自动尝试下一个来源。
# 留空则跳过更新检查，不影响使用。
#
# 支持两种形式：
#   1) 网络地址：https://example.com/cet-words/update.json
#      （GitHub Release 附件、对象存储、自己的服务器等任何可直接访问的地址）
#   2) 局域网共享：\\电脑名\共享目录\cet-words\update.json
#
